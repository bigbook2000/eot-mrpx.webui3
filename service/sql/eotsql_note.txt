(1) 以双横线 -- 作为语法标识
变量以#开始

(1) 通用SQL语句
-- sql
-- end

(2) 自增语句，将自增编号赋值给v1 #v2 #v3
-- inc #v1 #v2 #v3
-- end

(3) 读取数据赋值给变量v1, v2，不带#
-- var
select f1 as v1, f2 as v2
-- end

(4) IF嵌套，条件变量v1>0执行

-- end

(5) 系统变量

(6) 动态条件，当v1<>''执行，嵌套在set语句中

-- end

(7) FOR循环，对应List<Map>对象v_pack

-- end
